# Case Study 3: Data Visualisation

## Structure

```text
index.html
style.css
vendor/
  p5.min.js
src/
  core/
    sketch.js
    helper-functions.js
    gallery.js
    pie-chart.js
  visualizations/
    climate-change.js
    pay-gap-1997-2017.js
    pay-gap-by-job-2017.js
    tech-diversity-gender.js
    tech-diversity-race.js
data/
  ...
```

## Notes

- `src/core/` contains shared app code and reusable components.
- `src/visualizations/` contains one file per chart.
- `vendor/` holds third-party libraries.
- `data/` keeps the source datasets and original references.
